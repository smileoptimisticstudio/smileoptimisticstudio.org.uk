# Smile Optimistic Studio CIC website — Jekyll edition

GitHub Pages-ready **source** derived from the approved November 2026 site preview. The site remains on GitHub Pages and does **not** require Base44, WordPress or a paid CMS.

Folders: `_layouts/` templates, `_articles/` editable Markdown articles, `knowledge/index.html` auto-generated archive, `assets/` images and PDF; static pages under `studio-journal/`, `about/`, `work-with-us/`.

**Important**: Keep the existing `/hospital-joy-toolkit/` and `/hospital-joy-toolkit/feedback/` files in the live repository. This package does not replace them. Read `PREPUBLISH_CHECKLIST.md` before uploading.

Read `HOW_TO_PUBLISH.md` for a simple workflow. To build locally: install Ruby + Bundler, run `bundle install` then `bundle exec jekyll serve` (requires internet for gems if not installed).
