# Як публікувати на сайті SOS

Код чіпати не потрібно. Кожна публікація — це один текстовий файл. Після **Commit changes** GitHub сам збирає сайт за 1–2 хвилини.

| Що публікуємо | Папка | Шаблон | Адреса на сайті |
|---|---|---|---|
| Стаття, есей | `_articles/` | `templates/new-article.md` | `/knowledge/назва-файлу/` |
| Подія, виступ, новина | `_journal/` | `templates/new-journal-entry.md` | `/studio-journal/назва-файлу/` |

Нове з'являється само: у своєму розділі і на головній. На головній — 3 найновіші статті та 2 найновіші події, за полем `date`. Нумерувати нічого не треба.

## Додати статтю або подію

1. Відкрий шаблон у папці `templates/` і скопіюй увесь текст.
2. Перейди в `_articles/` (або `_journal/`) → **Add file → Create new file**.
3. Назва файлу англійською, малими літерами, через дефіс: `waiting-before-a-procedure.md`. Ця назва стане адресою сторінки.
4. Встав шаблон, заміни текст у лапках, напиши основний текст під другою лінією `---`.
5. **Commit changes.**

## Поля

- `date` — дата. Для статей вона визначає порядок і на сайті не показується. Для подій показується на картці.
- `category` — рубрика статті: `Emotional support in hospital`, `Patient experience`, `Disability and support`, `Cancer survivorship`.
- `image` — необов'язкове. Без нього стаття отримає фірмову текстову обкладинку з назвою.
- `gallery` (події) — додаткові фото. Непотрібні рядки можна видалити.
- `note` (статті) — дрібний текст унизу. Без нього: "A personal perspective… not medical or benefits advice."

## Картинки

**Add file → Upload files** у папку `assets/`. Назва латиницею без пробілів: `leeds-talk.jpg`. У шаблоні пишемо `/assets/leeds-talk.jpg`. Фото з телефона краще зменшити до ~1600 px.

## Не чіпати

- `hospital-joy-toolkit/` і `hospital-joy-toolkit/feedback/` — на ці адреси ведуть QR-коди на надрукованих картках.
- `_config.yml`, `_layouts/`, `_includes/`, `styles.css`.

## Якщо сайт не оновився

Вкладка **Actions**: червоний хрестик означає помилку в останньому файлі. Найчастіше це зайва або загублена лапка чи двокрапка в шапці файлу.
